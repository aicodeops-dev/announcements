## 💚 Free forever for open source

Maintainers of non-commercial open-source projects get AI CodeOps **free, for good**:

- Higher limits than the free plan (more workspaces, seats and AI models)
- **300 sessions a month** on the platform's models, then keep going on your own model key
- The **release-gate badge** for your README
- A usage meter in the console

**Who qualifies:** a public repository under an OSI-approved license, a non-commercial project, approved by application.

👉 **[Apply for the open source program](https://aicodeops.dev/pricing/open-source)**
